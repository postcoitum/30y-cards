# 30y-cards

[30년 전 오늘](https://github.com/postcoitum/30y) 카드뉴스의 **이미지 호스팅 전용 레포**입니다.

인스타그램/Buffer API는 이미지를 업로드받지 않고 **공개 URL로만** 가져갑니다
(`We cURL media used in publishing attempts`). 그래서 발행할 PNG를 여기에 올리고
GitHub Pages로 공개합니다.

- 코드·발행 이력·API 키는 전부 비공개 레포(`30y`)에 남아 있습니다. 여기엔 **발행할 카드 이미지만** 들어옵니다.
- 경로 규칙: `cards/<발행일 YYYY-MM-DD>/slide_<N>.png`
- 공개 URL: `https://postcoitum.github.io/30y-cards/cards/<발행일>/slide_<N>.png`

사람이 직접 편집할 일은 없습니다 — 발행 파이프라인이 자동으로 커밋합니다.
